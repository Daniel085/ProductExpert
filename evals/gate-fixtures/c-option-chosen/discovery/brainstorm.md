# Brainstorm — import recovery

## Framing (job story)

When my first import fails part-way, I want to recover without re-entering what already worked, so I can finish setup the same day and start using the product with my team.

## Options considered
1. Resume from the failed row  2. Pre-validate the file before import  3. Concierge import by support  4. Remove import; start from templates  5. Import in chunks with per-chunk retry  6. (inversion) Make failure impossible by accepting any file and fixing later
Set aside: 4 (removes the job), 6 (feasibility unknown).
