# Initiative scaffold

Copied by `/navigate start` into `initiatives/<slug>/`. Two files at the
root — `STATUS.md` (phase, gates, log) and `ledger.md` (the one assumption
ledger) — and a `discovery/` folder. The other phase folders
(`problems/`, `experiments/`, `options/`, `prfaq/`, `metrics/`) are
created by the first agent that writes to them.

Layout, gate definitions and the navigator's verbs:
[`docs/interaction-model.md`](../../docs/interaction-model.md).
